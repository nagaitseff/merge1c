# Установка и первый запуск

Нужен установленный Python 3.11 или новее. Для операций с репозиторием дополнительно нужен Git 2.50 или новее. Установка библиотеки не требует доступа к базе 1С.

`PATH` помогает оболочке находить программы. Python ищет установленные модули отдельно. Поэтому копирование каталога проекта в Scripts и добавление его в PATH не заменяют установку через pip. Сам `merge1c.exe` создаётся при установке.

## 1. Проверить Python

В cmd или PowerShell выполните:

```text
python --version
python -c "import sys; print(sys.executable)"
python -m pip --version
```

Последняя команда запускает pip именно для этого Python. Не заменяйте её просто на `pip`, если на компьютере установлено несколько версий Python.

Если pip отсутствует и Python сообщает `No module named pip`, установите встроенный pip:

```text
python -m ensurepip --upgrade
```

## 2. Установить merge1c

Ниже предполагается, что проект находится в `C:\i-merge\merge1c`. Если вы скопировали его в другое место, укажите свой путь. Команды подходят для cmd и PowerShell; переходить в каталог проекта не обязательно.

Предпочтительный способ — готовый файл из `dist`:

```text
python -m pip install "C:\i-merge\merge1c\dist\merge1c-0.1.1-py3-none-any.whl"
```

Это обычная установка, а не распаковка архива. Для установки только из локального файла без обращения к индексу пакетов можно добавить `--no-index --no-deps`: обязательных сторонних зависимостей у merge1c нет.

Если готового wheel нет, установите исходники:

```text
python -m pip install "C:\i-merge\merge1c"
```

Указанный каталог должен содержать `pyproject.toml`. При установке из исходников pip может загружать средства сборки, поэтому для компьютера без доступа в интернет удобнее готовый wheel.

Не нужно копировать `.py` или каталог `src/merge1c` вручную в Python. Пакет также не опубликован в публичном индексе от имени этого проекта: используйте путь к своему файлу или каталогу, а не команду `pip install merge1c` без пути.

## 3. Проверить запуск

```text
python -m merge1c --version
python -m merge1c --help
```

Первая команда должна вывести `merge1c 0.1.1`. Для такого запуска добавлять Scripts в PATH не требуется.

После этого можно создать настройки вашего репозитория:

```text
python -m merge1c init "C:\REP\erp"
```

`init` создаёт настройки проекта; установка пакета к этому моменту уже должна быть завершена.

## Короткая команда merge1c

Если `python -m merge1c --version` работает, а `merge1c --version` сообщает «команда не найдена», сам пакет уже установлен. Необходимо только сделать доступным созданный `merge1c.exe`.

Чтобы узнать его фактическое расположение, выполните:

```text
python -c "from importlib.metadata import distribution; d = distribution('merge1c'); print('\n'.join(str(d.locate_file(p).resolve()) for p in d.files or [] if p.name == 'merge1c.exe'))"
```

В PATH добавляется **каталог**, содержащий этот файл. После изменения PATH откройте новое окно терминала. Можно также продолжать пользоваться `python -m merge1c` и вообще не менять PATH.

В новом Python Install Manager есть отдельная команда обновления ярлыков `py install --refresh`. Она относится именно к этому менеджеру, а не к старому Python Launcher, и не заменяет установку пакета. Подробности — в [документации Python для Windows](https://docs.python.org/3.14/using/windows.html).

## Если после установки всё ещё No module named merge1c

Проверьте тем же Python:

```text
python -m pip show merge1c
python -c "import sys; print(sys.executable)"
```

Если `pip show` не находит пакет, установка не завершилась либо использовался другой Python. Повторите установку с `python -m pip` и убедитесь, что команда завершилась успешно. Изменение PATH не устраняет эту ошибку само по себе.

Если путь к wheel не существует, укажите место, куда вы действительно скопировали файл. Сообщения об ошибке установки нужно разобрать до запуска `init` и других команд merge1c.

## Отдельное окружение без прав администратора

Если не хотите устанавливать пакет в основной Python, создайте своё окружение в доступном вам каталоге, например в папке пользователя. Следующие строки одинаковы для cmd и PowerShell и не требуют активации:

```text
python -m venv ".\merge1c-env"
.\merge1c-env\Scripts\python.exe -m pip install "C:\i-merge\merge1c\dist\merge1c-0.1.1-py3-none-any.whl"
.\merge1c-env\Scripts\python.exe -m merge1c --version
```

Продолжайте запускать программу через этот интерпретатор из каталога, где создали `merge1c-env`. Если вы перешли в другой каталог, используйте полный путь к окружению. При смене Python пакет устанавливается в новое окружение отдельно.

Привязка pip к выбранному Python описана в [официальном руководстве pip](https://pip.pypa.io/en/stable/user_guide/#running-pip).
