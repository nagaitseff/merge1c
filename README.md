# merge1c

Python-библиотека и консольная программа для объединения файловой выгрузки 1С: XML, формы и BSL. Результат готовится отдельно от исходников; неоднозначные случаи остаются для ручного решения.

**Начните с [руководства пользователя](docs/guide.md).** Там последовательно описаны установка, каждый рабочий шаг, команды, доступ к каталогам, готовые возможности и планы.

## Установка

Нужны Python 3.11+ и Git 2.50+. Если библиотека находится в `C:/i-merge/merge1c`, выполните в cmd или PowerShell:

```text
python -m pip install "C:/i-merge/merge1c/dist/merge1c-0.1.2-py3-none-any.whl"
python -m merge1c --version
```

При другом расположении укажите свой путь. Без готового wheel: `python -m pip install "C:/i-merge/merge1c"`. Добавление каталога в PATH не заменяет установку. Для запуска через `python -m merge1c` Scripts в PATH не требуется.

Версия **0.1.2** готовит проверяемый кандидат; подтверждения работоспособности конкретной ERP или СППР без платформенных и прикладных испытаний она не даёт. Настоящие 1С и Beyond Compare в среде разработки пока не проверялись. Rebase и специальный перенос задач через cherry-pick находятся в плане, а не в готовых командах.
