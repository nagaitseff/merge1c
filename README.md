# merge1c

Python-библиотека и консольная программа для объединения файловой выгрузки 1С: XML, формы и BSL. Результат готовится отдельно от исходников; неоднозначные случаи остаются для ручного решения.

**Начните с [руководства пользователя](docs/guide.md).** Оно ведёт по конкретному случаю: включить `vendor/2.5.27.101` в уже созданную от master ветку `update/2.5.27.101`.

Порядок работы: подготовить файлы отдельно → решить спорные файлы → проверить результат → создать review-ветку → включить её в update обычным Git. В руководстве есть схема, точные команды и объяснение результата каждого шага.

## Установка

Готовая поставка находится в `dist`. Нужен Git 2.50+. Выберите один способ запуска:

- **Без установки Python:** распакуйте `merge1c-0.1.3-windows-x64.zip` в доступную папку. Запускайте `merge1c.exe` из неё или добавьте эту папку в PATH. Каталог `_internal` должен оставаться рядом с exe. Уже распакованная поставка: `dist/merge1c-0.1.3-windows-x64`.
- **Как библиотека Python:** нужен Python 3.11+. Выполните в cmd или PowerShell:

```text
python -m pip install --upgrade "C:/i-merge/merge1c/dist/merge1c-0.1.3-py3-none-any.whl"
python -m merge1c --version
```

При другом расположении укажите свой путь. Без готового wheel: `python -m pip install "C:/i-merge/merge1c"`. Для Python-варианта добавление каталога в PATH не заменяет установку; команда `python -m merge1c` работает без Scripts в PATH. Сборка из исходников описана в [разработке](docs/development.md#собрать-поставку).

Версия **0.1.3** готовит проверяемый кандидат. Для обычной работы без автоматического адаптера 1С руководство описывает ручную проверку в тестовой базе. Самостоятельный запуск 1С библиотекой при этом не заявляется. Настоящие 1С и Beyond Compare в среде разработки пока не проверялись. Rebase и специальный перенос задач через cherry-pick находятся в плане, а не в готовых командах.
