# Изменения

## 0.1.1

- Проверены PowerShell 5.1, PowerShell 7 и cmd с кириллицей, пробелами и внешним валидатором.
- Машинный вывод JSON использует ASCII-подстановки для защиты от старых кодовых страниц; файлы сессии остаются UTF-8.
- Добавлен `--quiet` для сценариев без вывода прогресса; уже включённый Git-коммит корректно возвращает JSON.
- Исправлены коллизии запланированных XML namespace, потеря перемещений комментариев и сравнение неизвестных числовых ссылок при remap ID.
- Неоднозначное локальное перемещение методов BSL теперь требует решения.
- Устранён квадратичный перебор правил переноса путей; сокращены повторные обходы при проверке сессии.
- Прямые Windows batch-обёртки отклоняются до запуска; поддерживаются явные интерпретаторы.
- Добавлены Ruff, проверки оболочек и новые регрессии.

## 0.1.0

- Python API и CLI для объединения трёх каталогов или снимков Git.
- Сохранение исходного XML, самостоятельные изменения свойств и вставки в прежние промежутки.
- Согласование ID формы по областям с переназначением коллизий наших добавлений.
- Консервативное объединение BSL по методам и проверка повторных объявлений.
- Сопоставление метаданных по контейнеру, типу и UUID, перенос связанных файлов при переименовании.
- Сессии, журнал, ручные решения и адаптер Beyond Compare.
- Внешние проверки, явный статус платформы и неизменяемый снимок настроек.
- Ветки-кандидаты с двумя родителями, CAS-проверки и закрепление входов от GC.
- Документация, демонстрационный пример и воспроизводимые измерения.
